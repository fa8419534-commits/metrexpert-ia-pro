# Vérification visuelle MVP

La page publique a été vérifiée en vue desktop 1280×900 et mobile 390×844. La hiérarchie est lisible, le formulaire reste accessible sur mobile, le dépôt facultatif est identifiable et le bouton principal reste visible. Aucun débordement visuel notable n’a été observé dans ces deux vues.

Points fonctionnels à vérifier manuellement avec un vrai appel IA : l’affichage de l’état de chargement, les erreurs API, l’acceptation PDF/image et le téléchargement effectif du classeur généré.
